Panduan Penggunaan

Beranda Kalender Riwayat Tentang Panduan

Cara Menggunakan Aplikasi

  1. Buka halaman Beranda (index.html) lalu klik Mulai Penyegaran atau pilih kartu bahan bacaan yang diinginkan.
  2. Gunakan menu Kalender untuk memilih pekan (01–12) dan hari (0_garis_besar hingga 6_sabtu).
  3. Jika tombol versi _03 tidak aktif pada hari tertentu, artinya file _03 untuk hari tersebut belum tersedia dan Anda tetap dapat membaca versi _01.
  4. Jika tampilan belum berubah setelah mengedit file HTML atau Service Worker, lakukan hard reload (Ctrl + Shift + R).
